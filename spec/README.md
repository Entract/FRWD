# Specification

The normative FRWD specification will be published here as `FRWD-0.1.md` when
0.1 is frozen.

Until then the working draft is authoritative and lives in the design pack:

- **[`plan/docs/02_FRWD_FORMAT_SPEC_V0_1.md`](../plan/docs/02_FRWD_FORMAT_SPEC_V0_1.md)** — format spec, draft 0.1
- [`plan/docs/03_FLOWING_DOCUMENT_MODEL.md`](../plan/docs/03_FLOWING_DOCUMENT_MODEL.md) — flowing document model
- [`plan/docs/04_STYLE_LAYOUT_AND_PAGINATION.md`](../plan/docs/04_STYLE_LAYOUT_AND_PAGINATION.md) — style, layout and pagination
- [`plan/docs/06_AI_NATIVE_EDITING_PROTOCOL.md`](../plan/docs/06_AI_NATIVE_EDITING_PROTOCOL.md) — AI operations
- [`plan/docs/05_RICH_MEDIA_AND_INTERACTIVITY.md`](../plan/docs/05_RICH_MEDIA_AND_INTERACTIVITY.md) — rich components
- [`plan/docs/09_SECURITY_TRUST_AND_PORTABILITY.md`](../plan/docs/09_SECURITY_TRUST_AND_PORTABILITY.md) — security and portability

There is deliberately **one** copy of each document. A specification that exists
in two places drifts.

If these documents conflict, the precedence order in
[`plan/docs/00_START_HERE.md`](../plan/docs/00_START_HERE.md) decides.
