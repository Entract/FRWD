# @frwd/operations

The AI-native editing protocol as deterministic, testable operations over stable
document objects: insert, replace, delete and move blocks, set attributes,
restyle without changing content, and the addressing scheme that targets
`data-frwd-id`.

Pure functions over the format model. No AI chat UI, no network, no model vendor
dependency — deterministic operations come first, conversation later.

Framework-agnostic.
