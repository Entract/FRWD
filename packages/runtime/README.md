# @frwd/runtime

The trusted standard FRWD browser runtime embedded in a `.frwd.html`
publication: edit mode, safe rich interactivity, Save As, and print/export
helpers.

This is the *only* script a FRWD publication carries. Documents never contain
arbitrary JavaScript; the runtime is standard, inspectable and identical across
publications.

Self-contained and framework-agnostic — a publication has no external
dependencies at open time.
